Patient VB — Semantic Residual Analysis (Deep Dive)

VB shows the strongest semantic contamination across all patients (55% accuracy drop). This report dissects all three conditions to understand why.
Key finding: VB's phoneme model was almost entirely exploiting semantic structure. After projecting out semantic dimensions, category accuracy collapses from 25–28% → 12%. Meanwhile, the semantic-only condition achieves 38–42% — dramatically outperforming the phoneme model.

4. The Reversal: sem_only vs normal

If the phoneme model were capturing genuine phonological structure, it should outperform a model restricted to semantic dimensions. Instead, VB shows a complete reversal — the semantic-only model dominates.

Reversal magnitude:
panphon: sem_only (0.417) vs normal (0.253) → +64% relative gain
token_ipa: sem_only (0.385) vs normal (0.282) → +37% relative gain
This is the strongest evidence that VB's phoneme model was entirely exploiting semantic co-representation.

6. Best Bin Shift

The optimal time bin shifts dramatically for panphon after residualization (bin 21 → 48), suggesting the model switches from an early semantic-rich window to a late window searching for phonological signal. token_ipa stays stable (bin 20).

7. Interpretation for VB

Why VB is special: VB likely has broader electrode coverage over semantic cortex (temporal / anterior insula) relative to motor cortex, compared to other patients. This means:
  • The neural feature space is dominated by semantic dimensions
  • PLS naturally finds these high-variance semantic directions first
  • Phoneme embeddings correlate with semantic structure (r(phon,sem) ≈ 0.085), giving PLS a shortcut
  • After Gram-Schmidt projection removes these dimensions, only noise remains for phonology
